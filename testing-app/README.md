# ISAI Testing App

A lightweight browser-based QA harness for the ISAI prototype.

## Tests
1. UI suite
2. Local audio playback
3. Library/file import inspection
4. JavaScript performance stress
5. 2,000-row rendering stress

## Run
Open `testing-app/index.html` in Acode or a mobile browser.

## Important
This is a prototype test harness. It cannot validate Android-specific MediaSession, foreground services, lock-screen controls, Android Auto, native audio focus, or device-specific audio behavior. Those require the native Android APK test stage.

No packages are required to run this test app.
